# Huffman Compressor (modular)

Estrutura modular em src/huffman com os seguintes módulos:
- tokenizer.py
- frequency.py
- tree.py
- builder.py
- encoder.py
- serializer.py

Entrypoint: src/main.py

Como usar:
1. Coloque os textos em data/input.dat (separe com linha em branco).
2. Rode:
   cd src
   python3 main.py

O output será escrito em data/output.dat
